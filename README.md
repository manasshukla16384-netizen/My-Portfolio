# Manas Shukla — Personal Portfolio

A premium, responsive one-page portfolio built with plain HTML, CSS and JavaScript.

## Preview

Open `index.html` directly in a browser. No build step or dependencies required.
Optionally serve it locally:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Sections

Hero · About · Education · Technical Skills · Projects · Guitar & Music · Contact

## Before publishing

Replace the placeholder details:

1. **Email** — `manas.shukla@email.com` appears in `index.html` and `script.js`.
2. **Social links** — GitHub, LinkedIn and Instagram currently point to their homepages. Add your profile URLs in `index.html`.
3. **Education** — the timeline says `B.Tech · Computer Science & Engineering`; adjust the degree/year if needed.
4. **Projects** — the three cards are concept/practice projects based on your skills. Swap in real project details and links when ready.
5. **Skill meters** — the widths (`data-level`) are illustrative; tune them to match your comfort level.

Fonts load from Google Fonts, with system font fallbacks if offline.
